Git Repository Management for a Django Project

Choose difficulty:
1. A developer accidentally commits their .env file containing the production SECRET_KEY and database credentials to GitHub. What is the mandatory immediate response?
2. You add db.sqlite3 to .gitignore, but git status still reports changes to it whenever you run local queries. What command removes it from tracking without deleting your local database file?
3. A teammate defines new models in polls/models.py, executes makemigrations, but only stages and commits models.py (forgetting 0001_initial.py). What will happen when teammates pull and run python manage.py migrate?
4. When resolving a merge conflict in mysite/urls.py, what does the marker <<<<<<< HEAD designate?
5. In the standard Git Flow model for web applications, which branch must remain stable, production-ready, and identical to live deployment?
