# Git Repository Management for a Django Project

> An interactive Virtual Labs experiment for learning practical Git workflows in Django projects.

This experiment introduces repository setup, branching, merging, conflict resolution, migration management, and safe handling of project configuration. It combines concise learning material with assessments and a browser-based simulation.

## Experiment sections

| Section | Description |
| --- | --- |
| Aim | Learning objectives for the experiment |
| Theory | Core Git and Django repository concepts |
| Pretest | Questions to assess prior knowledge |
| Procedure | Guided steps for completing the experiment |
| Simulation | Interactive practice environment |
| Posttest | Questions to evaluate understanding |
| References | Books and online learning resources |

## Run locally

No installation or build step is required.

1. Download or clone this repository.
2. Open `index.html` in a modern web browser.
3. Use the sidebar to move through the experiment.

For the best local experience, the site can also be served with any simple static web server.
